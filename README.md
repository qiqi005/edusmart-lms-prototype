# EduSmart360 - Learning Management System Prototype

C++ command-line Learning Management System (LMS) prototype implementing Role-Based Access Control (RBAC) and academic workflow management.

## Tech Stack & Concepts
- Language: C++
- Concepts: Role-Based Access Control (RBAC), Data Structures , File or Console I/O handling.

## Key Features
- Multi-Role Authentication: Customized dashboard and functionality for Admin, Instructor, Student, and Guest roles.
- Course & Content Management: Allows instructors to publish materials and create assignments.
- Submission & Grading System: Students can submit assignment entries; Instructors can evaluate and record numeric grades and text feedback.
